# Leave a flexible settling window before quota reset

**User correction, 2026-10-31:** for quota-budgeted weekly sweeps, prefer a flexible cutoff for **starting new work** roughly 15–30 minutes before the quota reset, allowing started work about 30 minutes to settle. Stopping 75 minutes early was too conservative.

The user explicitly endorsed 18:30–18:45 for a 19:00 reset. This illustrates the relative window; it is not a standing reset time.

Apply this when scheduling a quota-budgeted weekly sweep. Distinguish the new-work cutoff from terminating work already underway, and use the current reset time and explicit task constraints. Do not generalize this preference into a deadline for unrelated work.
