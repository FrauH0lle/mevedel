# Show recurring advisories only once

User statement, 2026-10-14: recurring advisories should be shown only once because they “get tedious over time.”

The example was the warning that another session writer is active and independent sessions can race over project files, suggesting a Worktree Fork before asking whether to start anyway.

Apply this preference to repeated informational advisories and similar warnings. The statement did not specify whether “once” means per installation, project, or session, and does not authorize suppressing required permission approvals or warnings about materially new consequences.
