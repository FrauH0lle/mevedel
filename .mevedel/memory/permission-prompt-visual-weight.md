# Reduce permission prompts' visual weight

User statement, 2026-10-12: permission prompts feel “very big and imposing,” and sandbox/permission prompts feel “clumsy.”

For permission-prompt UI work, the user prefers **collapsing parts of the prompts to reduce their visual weight**. The statement does not specify which sections should collapse or authorize hiding consequential permission information.
