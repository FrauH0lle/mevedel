# Keep selected extraction automatic without making notes permanent

**User correction, 2026-10-11:** automatic extraction is necessary because manual extraction is easily forgotten. When the user selects automatic operation, “automatic means automatic”—do not replace that selected operation with reminders to initiate it or recurring requests to confirm it.

**User clarification, 2026-10-29:** shared notes are temporary working material where sessions and agents may freely create files and handoffs. Memory is the permanent layer, fed by qualifying evidence from both journals and shared notes. Cleanup should lean toward deletion because models produce large amounts of text quickly, rather than turning shared notes into another permanent store.

**How to apply:** when designing or evaluating an explicitly selected automatic extraction workflow, make extraction genuinely automatic within its authorized scope. Preserve qualifying durable knowledge, not every observation or piece of unfinished work. A note's existence does not justify a memory.

Use current project instructions and maintained lifecycle documentation for destinations, skill-workflow exceptions, extraction eligibility, and disposal mechanics. These preferences do not grant write authority, bypass permission boundaries, or override a read-only request.
