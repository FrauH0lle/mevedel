---
name: "Indicate new memory candidates without changing views"
description: "Background discovery should notify about candidates rather than navigate automatically."
type: feedback
---

When background discovery finds new memory candidates, do not automatically switch the memory table to the Candidates view. The user said that automatic switching is confusing and suggested indicating that new candidates are available instead.

Apply this rule to background discovery and navigation in the memory UI; it does not establish a broader preference about navigation in unrelated features.
