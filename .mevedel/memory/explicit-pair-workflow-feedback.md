# Actively use a partner when pair work is invoked

User correction, 2026-10-15:

> “$pair remember to utilize your partner”

When the user explicitly invokes `$pair` for implementation, actively involve the partner in the work rather than implementing solo while leaving the partner unused.

**Why:** The user's correction identifies actual partner participation as part of the requested workflow. Merely having a partner available does not satisfy that expectation.

This does not establish a preference for delegation on every task, a particular partner model or effort level, or a mandatory division of work. Work splitting and mutual diff review were the journal's interpretation of how to implement the request, not separately quoted user requirements.
